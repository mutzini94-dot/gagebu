# 월별 가계부

월별 수입(급여·기타)과 고정비(카드값·대출·보험·용돈·저축)를 입금계좌·입금일과 함께 관리하는 한 페이지짜리 가계부입니다.

- `index.html` — 브라우저에서 바로 여는 독립 실행 파일 (GitHub Pages용). 데이터는 그 브라우저에 저장됩니다.
- `budget.html` — claude.ai Artifact 게시용 원본. 로그인한 내 계정에 비공개로 저장됩니다.

`index.html`은 `budget.html`을 HTML 문서 뼈대로 감싼 것이므로, 수정은 `budget.html`에서 하고 `index.html`을 다시 만들어 주세요.

## 기능

- 월별 수입 입력, 지난달 수입 가져오기
- 고정비 항목 등록 (분류·금액·입금계좌·입금일), 달마다 금액 조정과 이체 완료 체크
- 날짜별 이체 일정, 계좌별 필요 금액
- 월 요약 텍스트 복사 (메신저 공유용)
- 진입 시 비밀번호 잠금

비밀번호 잠금은 화면을 가리는 용도이며, 소스가 공개된 정적 페이지라 보안 장치는 아닙니다.
